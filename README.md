# ☕ Java Pattern Programming

A collection of Java pattern programming exercises designed to strengthen logical thinking, problem-solving skills, and nested loop concepts.

This repository contains **23 Java pattern programs**, covering basic to advanced star, number, alphabet, pyramid, and geometric patterns.

## 📌 Project Overview

The main objective of this repository is to improve Java programming fundamentals through practical pattern-based problems.

Each pattern is implemented using Java loops, conditional statements, variables, and mathematical logic.

## 🛠️ Technologies Used

- **Programming Language:** Java
- **Core Concepts:** Nested Loops, For Loops, Conditional Statements
- **IDE:** Eclipse IDE
- **Version Control:** Git & GitHub

## 📚 Topics Covered

| No. | Pattern Category | Description |
|---|---|---|
| 01 | Square Patterns | Solid square and rectangular patterns |
| 02 | Triangle Patterns | Increasing and decreasing triangles |
| 03 | Number Patterns | Sequential and repeated number patterns |
| 04 | Pyramid Patterns | Pyramid and inverted pyramid |
| 05 | Diamond Patterns | Full diamond and half diamond |
| 06 | Alphabet Patterns | Character-based patterns |
| 07 | Hollow Patterns | Hollow square and rectangular patterns |
| 08 | Symmetrical Patterns | Butterfly and symmetrical designs |
| 09 | Advanced Patterns | Complex geometric and mathematical patterns |

## ✨ Key Features

- 23 pattern programming methods.
- Beginner-to-advanced pattern exercises.
- Star, number, and alphabet-based patterns.
- Practical implementation of nested loops.
- Improved logical thinking and coding practice.
- Useful for Java interviews and coding assessments.

## ▶️ How to Run

1. Clone this repository:

   ```bash
   git clone https://github.com/DebashisTech/Java-Pattern-Programming.git
   ```

2. Open the project in Eclipse IDE or IntelliJ IDEA.

3. Navigate to `DevPattern.java`.

4. Run the Java program.

5. Change the method arguments to experiment with different pattern sizes.
